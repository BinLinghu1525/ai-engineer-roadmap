# Data Structures & Algorithms

## Learning Goals

- Select data structures based on access patterns and complexity trade-offs.
- Recognize common algorithm patterns and explain their correctness.
- Develop solutions independently before using AI for review.

## Key Topics

- Arrays, hash maps, linked lists, stacks, queues, trees, heaps, and graphs
- DFS, BFS, binary search, two pointers, and sliding windows
- Backtracking and dynamic programming
- Time and space complexity

## Practice Tasks

- Classify problems by data structure and algorithmic pattern.
- Write test cases and complexity analyses before implementation review.
- Compare alternative approaches and identify edge cases.
- Maintain concise notes on mistakes and reusable patterns.

## Completion Criteria

- Implement representative problems without copying complete solutions.
- Explain correctness and complexity for each reviewed solution.
- Test boundary conditions and revise solutions based on evidence.
- Demonstrate coverage across the module's core structures and patterns.
