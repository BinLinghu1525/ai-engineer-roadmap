# Docker

## Learning Goals

- Package applications into reproducible container environments.
- Understand images, containers, storage, networking, and configuration.
- Debug container build and runtime issues systematically.

## Key Topics

- Images and containers
- Dockerfiles and build context
- Volumes and networks
- Environment variables and secrets boundaries
- Docker Compose
- Logs and containerized development

## Practice Tasks

- Plan a minimal image for a small Python service.
- Compare bind mounts, named volumes, and image-contained files.
- Define a local multi-service environment with Docker Compose.
- Inspect logs and diagnose a controlled startup failure.

## Completion Criteria

- Build and run a reproducible container when the module begins.
- Explain Dockerfile layers, networking, storage, and configuration choices.
- Avoid embedding secrets or unnecessary artifacts in images.
- Document build, run, debugging, and cleanup commands.
