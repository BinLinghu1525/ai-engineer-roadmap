# Agent Engineering

## Learning Goals

- Understand agents as controlled loops over models, tools, state, and observations.
- Design reliable workflows with explicit context and failure handling.
- Evaluate agent behavior through reproducible tasks and traces.

## Key Topics

- Agent loops, tool calling, and observations
- Planning, state, and workflows
- Memory and context engineering
- LangGraph
- Human-in-the-loop controls
- Agent evaluation

## Practice Tasks

- Specify an agent loop and its termination conditions before implementation.
- Design typed tool interfaces and failure scenarios.
- Compare workflow, planning, and memory strategies on controlled tasks.
- Create an evaluation set and analyze unsuccessful traces.

## Completion Criteria

- Explain the responsibilities and risks of each agent component.
- Build a bounded agent workflow when this module begins.
- Test tool errors, termination, state transitions, and human intervention.
- Report evaluation methodology and bad cases without fabricated success claims.
