# SQL

## Learning Goals

- Query and transform relational data accurately.
- Understand schema, index, and transaction trade-offs relevant to AI applications.
- Validate query results rather than relying on visual plausibility.

## Key Topics

- `SELECT`, `WHERE`, `GROUP BY`, and `CASE WHEN`
- Joins, subqueries, and common table expressions
- Window functions
- Indexes and query performance concepts
- Transactions and consistency

## Practice Tasks

- Design queries for filtering, aggregation, and multi-table analysis.
- Compare equivalent queries using joins, subqueries, and CTEs.
- Use window functions for ranking and rolling calculations.
- Inspect how indexes and transactions affect representative workflows.

## Completion Criteria

- Write correct queries for representative relational problems.
- Explain join cardinality, null handling, and aggregation pitfalls.
- Use transactions safely in a small application workflow.
- Verify results with controlled fixtures and documented expectations.
