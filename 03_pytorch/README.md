# PyTorch

## Learning Goals

- Understand tensor computation, automatic differentiation, and neural network modules.
- Build transparent training, validation, checkpointing, and inference workflows.
- Diagnose common shape, device, and optimization issues.

## Key Topics

- Tensors and tensor operations
- `Dataset`, `DataLoader`, and data pipelines
- `nn.Module` and autograd
- Loss functions and optimizers
- Training loops and validation
- Checkpoints and inference

## Practice Tasks

- Explore tensor shapes, broadcasting, devices, and gradients.
- Build a small dataset and inspect batched data.
- Design a minimal training and validation loop.
- Save, load, and verify a checkpoint for inference.

## Completion Criteria

- Explain gradient flow and the responsibilities of each training-loop stage.
- Train and validate a small model with reproducible configuration.
- Restore a checkpoint and reproduce inference behavior.
- Document observed failures, debugging steps, and limitations.
