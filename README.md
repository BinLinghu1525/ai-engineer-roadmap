# AI Engineer Roadmap

A structured learning journey toward LLM Application Engineering and AI Agent Engineering.

## About Me

I'm a master's student systematically developing practical AI engineering skills, with a particular interest in LLM applications, AI agents, RAG, agent evaluation, and AI-assisted software engineering.

My current background includes Python, data analysis, LLM API usage, prompt engineering, experimental evaluation, simulation, and AI-assisted coding. This repository documents my transition from research-oriented AI experimentation toward production-oriented AI engineering.

## Learning Objectives

- Strengthen software engineering fundamentals and write maintainable Python.
- Build working knowledge of algorithms, SQL, databases, and API development.
- Understand PyTorch and Transformer systems from core concepts to inference.
- Design, evaluate, and debug RAG and agent-based applications.
- Learn MCP, FastAPI, Docker, and reproducible development workflows.
- Produce evidence-based portfolio work without overstating progress.
