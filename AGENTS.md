# AGENTS.md

## Repository Purpose

This repository is primarily educational. Its purpose is to help the repository owner become independently capable of designing, implementing, debugging, testing, and explaining AI engineering systems.

## Working Rules

- Read this file and the relevant module README before making significant changes.
- Understand the learning objective of the current module.
- Explain concepts before proposing code for learning tasks.
- Prefer teaching and review over blindly completing exercises.
- Do not solve algorithm exercises unless explicitly requested.
- Do not automatically implement an entire learning module.
- Summarize the plan before significant changes.
- Prefer small, reviewable changes.
- Do not modify unrelated modules.
- Avoid unnecessary dependencies.
- Follow existing repository conventions.

## Code Quality

- Keep code readable and use type hints where appropriate.
- Use meaningful names and add docstrings to meaningful public functions and classes.
- Handle errors explicitly.
- Add tests for meaningful functionality.
- Avoid dead, placeholder, or fake code presented as complete.

## Verification

- Run relevant tests when available.
- Never claim tests passed unless they were actually executed.
- Report executed checks and failures honestly.
- After implementation, explain what changed and how the repository owner can verify it.

## Security

Never commit API keys, passwords, tokens, credentials, private keys, `.env` files, or other secrets. Use environment variables for sensitive configuration.

## Git

- Prefer small, logical commits and suggest meaningful commit messages.
- Never force push or rewrite history without explicit permission.
- Never execute destructive Git operations without approval.

## Educational Principle

The goal is not merely to produce working code. The repository owner should be able to understand, explain, debug, test, and independently reproduce each implementation.
